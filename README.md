# CRM System

A full-stack CRM project with a separate frontend and backend.

## Structure

```text
CRM/
├── frontend/       # React + TypeScript client app
├── backend/        # Node.js + Express + TypeScript API
└── docs/           # Planning, API notes, and project documentation
```

## Frontend

The frontend is organized by feature, making it easier to scale CRM modules like contacts, companies, deals, tasks, authentication, and dashboard views.

## Backend

The backend separates routes, controllers, services, models, middleware, validators, and configuration.
