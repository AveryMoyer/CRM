# CRM Architecture

## Frontend Modules

- **Auth**: login, registration, sessions, password reset
- **Contacts**: people, notes, activities, communication history
- **Companies**: organizations, accounts, relationships
- **Deals**: pipeline stages, values, probability, close dates
- **Tasks**: follow-ups, reminders, ownership
- **Dashboard**: metrics, charts, recent activity

## Backend Layers

- **Routes**: HTTP endpoint definitions
- **Controllers**: request and response handling
- **Services**: business logic
- **Models**: data access and database entities
- **Validators**: request validation schemas
- **Middleware**: auth, logging, errors, security
- **Config**: environment and infrastructure settings
